extension Resolução IPv6 (Delegação de Prefixo)

O análogo IPv6 do VLSM. Em IPv6 a LAN é sempre /64 (2^64 endereços via SLAAC), então não se dimensiona por número de hosts — planeja-se por quantidade de sub-redes. Informe um bloco base e os nomes das redes: cada uma recebe um bloco contíguo, com faixa e gateway.

extension Planejar delegação

Ex.: base 2001:db8::/48, alvo /64, uma sub-rede por linha em "Nomes".

/64 é o padrão de LAN (SLAAC).
extension

Informe o bloco base, o prefixo alvo e os nomes das sub-redes para ver o plano de delegação: cada rede com seu bloco /alvo, faixa de endereços e gateway sugerido.
